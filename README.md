## 📖 Replicated Building System | Реплицированная строительная система

**Update V4 RU:**
- Улучшение репликации
- Исправление ошибки

**Update V4 ENG:**
- Replication Improvement
- Bug Fix

**Update V3 RU:**
- Добавлена поддержка каркасной сетки

**Update V3 ENG:**
- Added Skeletal Mesh Support

**Updated V2 RU:**
- Добавлена интерактивность для перекрестия.
- Изменен стиль отладки.
- Добавлена функция создания и использования элемента.
- Добавлена переменная с именем "Длина трассировки привязки", позволяющая регулировать длину трассировки с помощью стрелок, которые вы добавляете для управления попаданиями.
- Добавлена переменная с именем "Отладка для отключения материалов", чтобы при ее активации ваш элемент сохранял исходные материалы.
- Добавлена функция обновления перенесенного вами актера на его старое место.

**Updated V2 ENG:**
- Added interactivity for Crosshair.
- Debug style changed.
- Added function to spawn and use item.
- A variable named "Snap Trace Length" has been added so that you can adjust the trace length from the arrows you add to control hits.
- A variable named "Debug for Disable Materials" has been added so that when you activate it, your item will keep its original materials.
- Added function to update the actor you have taken to its old place.

**Особенности RU:**

- Поддержка одиночной или многопользовательской игры!
- Вы можете вращать свой предмет
- Вы можете изменить вращение вашего товара
- Ты можешь брать свои вещи туда и обратно
- Вы можете увеличивать или уменьшать масштаб вашего предмета для вашего персонажа.
- Вы можете установить пределы увеличения и уменьшения масштаба изображения.
- Вы можете настроить автоматическую привязку вашего изделия
- Вы можете отфильтровать свой товар для автоматической привязки
- Вы можете легко изменить настраиваемые допустимые и недопустимые материалы.
- Вы можете легко изменить допустимые и недопустимые цвета.

- Количество чертежей: 9
- Сетевая репликация: Да ✔️
- Поддерживаемые платформы разработки: Windows, Mac
- Поддерживаемые целевые платформы для сборки: Windows, Mac, Linux, Android, iOS

**Features ENG:**

- Singleplayer or Multiplayer support!
- You can rotate your item
- You can reset your item's rotation
- You can take your stuff back and forth
- You can zoom in or out your item to your character.
- You can setthe zoom in and out limits.
- You can have your item auto-snap
- You can filter your item to auto-snap
- You can easily change the customizable valid and not valid materials.
- You can easily change valid and not valid colors.

- Number of Blueprints: 9
- Network Replicated: Yes ✔️
- Supported Development Platforms: Windows, Mac
- Supported Target Build Platforms: Windows, Mac, Linux, Android, iOS
